# Source and adaptation inventory

The candidate was assembled into a new directory through an explicit initial allowlist of 59 source/test/assets from the personal app. It has no inherited Git directory, history or remote. New demo/setup/documentation files were authored in this candidate. No saved record or private fixture was copied.

| Area | Candidate treatment |
| --- | --- |
| Research and portfolio React components | Retained, with local navigation and synthetic-data labels, unavailable-score display correction and demo anchor offsets. |
| Annual-core policy, scoring and Autopilot engine | Retained without financial-policy redesign. |
| Pure explanation, risk, financial-metric and chart modules | Retained; quote-source allowlists changed to the isolated authored source label. |
| Portfolio chart effect | Existing benchmark dependency included for consistent refresh behavior. |
| Company groups and business text | Fictional membership and authored descriptions. |
| Citation/claim register and saved targets | Empty candidate registers; targets show unavailable. |
| Historical share basis | Retained type shape only, required by the risk module; no captured filing history or ingestion implementation. |
| Styles and favicon | Retained assets; system fonts replace font downloads. Owner asset rights remain part of the licence review. |
| Unit tests | Selected pure-module suites and helper retained; one SEC-ingestion test removed from the risk suite because its server route is excluded. Five demo-boundary tests added, and the existing score-format test now covers null. |
| Operational app | Routes, backend/database/tracker implementations, provider scripts, owner sessions, deploy configuration and jobs excluded. |
| State and personal material | Environment files, credentials, configuration secrets, logs, provider captures, source data registers, saved portfolios/trades, backups and history excluded. |

The exact distributable file list is `release-files.json`. `release:archive` adds a generated `MANIFEST.sha256` to the archive; its checksums describe candidate bytes, not original private-source paths. Private preparation/preservation evidence remains outside the candidate.

Unchanged-module provenance and original-state comparisons were recorded locally during preparation. They are not bundled because they include private workspace context. The original source/runtime were read for review and preservation checks, with no edits or service-control operations performed on them.
